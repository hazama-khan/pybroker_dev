Installation
============

PyBroker supports Python 3.11+ on Windows, Mac, and Linux. **We recommend
installing Python 3.12**, the tooling version used to build and test PyBroker,
for the best experience. Download it from
`https://www.python.org/downloads/ <https://www.python.org/downloads/>`_ and
make sure it is on your ``PATH`` before installing PyBroker.

You can install PyBroker using ``pip``:

.. code-block:: console

    pip install -U lib-pybroker

Or you can clone the Git repository with:

.. code-block:: console

    git clone https://github.com/edtechre/pybroker
